- **H6936 follow-up — the UTF-8 validity residual is now a wired gate: CI (required), native pre-commit, and the pre-commit framework.** [`tools/utf8_gate.py`](https://github.com/gasyoun/SanskritLexicography/blob/master/tools/utf8_gate.py) stream-decodes every tracked file with an incremental decoder (a multi-byte character split across a 1 MiB chunk edge is legal — the H6936 false-positive class), classifies binaries by content (NUL byte in the first 8 KiB) rather than by extension, and refuses UTF-16/32 with or without a BOM (BOM-less UTF-16 ASCII is matched by an interleaved-plane test, so a plain NUL sniff cannot silently skip it). Measured on `master` at the wiring commit: **5,312 text files / 46 binaries / 5,358 tracked, 0 invalid, 1.2 s**; `--selftest` is **10/10** — valid UTF-8, a UTF-8 BOM, an empty file and a 1 MiB chunk-boundary file pass; a stray `0xFF`, a truncated sequence, a UTF-16 LE BOM, BOM-less UTF-16 and a PNG-like binary control behave exactly as declared. Wired on three surfaces: CI job **UTF-8 validity** in [`.github/workflows/ci.yml`](https://github.com/gasyoun/SanskritLexicography/blob/master/.github/workflows/ci.yml) (added to the required `master` status checks), [`.githooks/pre-commit`](https://github.com/gasyoun/SanskritLexicography/blob/master/.githooks/pre-commit) over staged A/C/M/R files, and a local hook in [`.pre-commit-config.yaml`](https://github.com/gasyoun/SanskritLexicography/blob/master/.pre-commit-config.yaml). Refusals proven on the real paths, not assumed: a staged file carrying byte `0xFF` was refused by the hook (commit exit 1), and the CI proof run is linked from PR [#2427](https://github.com/gasyoun/SanskritLexicography/pull/2427).
