# DEAD_ENDS §15: direct-Anthropic Batches probe lane закрыт решением MG

Линия зондирования Anthropic Message Batches API как асинхронного транспорта PWG→RU закрыта навсегда — не по измеренному NO-GO, а по решению принципала от 19-11-2026: «There will be no anthropic api ever. Use it via openrouter key for nonexpensive tasks when allowed to». Единственный когда-либо подготовленный ключ аутентифицируется (401 из сентября снят), но поверхность /v1/models для него закрыта целиком (равномерный 404 по list, по закреплённому claude-sonnet-5 и по контрольному фиктивному id), поэтому обязательный пред-submit модельный чек платного плеча непроходим в принципе. Сам транспорт слит и здоров (PR #2303, офлайн-гейты зелёные) — линия мертва на креденшале, не на коде. Запись §15 в DEAD_ENDS.md фиксирует measured reason, условие неповторения (только через OpenRouter, если появится batches-совместимая поверхность) и то, что исходный latency-слепой-пункт (аудит скорости, ledger #8 / action A8) закрывается этим решением. Судьба строки H4531 — очередь кросс-семейного верификатора, закрытие класса money остаётся за человеком.
