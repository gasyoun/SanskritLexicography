## Goal restated (both lanes; from H2240, not the residual summary)

1. **Writer** — a single append-only `health_probe_log.jsonl` is the writer target for
   c4/gate0 (and sibling) probes.
2. **Reader** — `kitchen_slices.health_ribbon` reads the canonical path first (prefer
   exclusively when present).
3. **Migrate / document** — existing per-account probe files are folded or documented;
   README names the path.
4. **Fail =** still only ad-hoc `*probe_events.jsonl` globs with no writer contract.

## Independent Grok diagnosis (before treating #1120 as authority)

| Acceptance item | Independent finding | Evidence |
|---|---|---|
| Writer target | Every `live_probe` reading must land in ONE file under `pilot/output/`, independent of which script/account invoked the probe | All paid probes funnel through `live_probe` → `_emit` (`max_account_orchestrator.py`) |
| Keep per-account files | Gate reports (H1110/H1447/H858) cite `events_path` by path; exact-run_id read discipline (#729) must not change | Dual-write is required, not replace |
| Reader preference | When the canonical file exists, glob-scraping siblings would **double-count** after migration; exclusive prefer is correct | Pre-H2240 fallback still needed for unmigrated checkouts |
| Migrate | Pre-H2240 history lives only in per-account files until folded once | Residential `pilot/output`: canonical had **2** rows; legacy files had **35** probe_call-bearing lines; dry-run migrate → **25 new rows** (dedupe-aware) |
| README path | H2240 acceptance explicitly names "README path" | `progress_dashboard/README.md` had **zero** `health_probe` / `probe_events` mentions before this residual |

**Defect found in Sonnet override (not a rubber-stamp):**

`_emit` nested the canonical `append_event(HEALTH_PROBE_LOG, …)` **inside**
`if events_path:`. A `live_probe(..., events_path=None)` call (selftests,
`probe_fleet` without a file, ad-hoc scripts) never wrote the kitchen log, contradicting
H2240's "every probe call routes through `_emit`" contract. Grok residual un-nests the
canonical write so it is always best-effort.
