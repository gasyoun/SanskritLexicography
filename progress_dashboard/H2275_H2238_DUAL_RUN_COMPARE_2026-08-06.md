## Goal restated (both lanes)

1. Progress shows **nominal burn-down** (promoted / scope / remaining / pct), not only raw worklist counts.
2. **medium-50** band is live-measured where possible (not only a hardcoded `2/50`).
3. Pause reason is a **structured code object** (code + label + docs), not prose-only `medium50_status`.
4. UI has an ETA-like **Nominal burn-down** strip next to Verb burn-down.

**Fail =:** still only a `medium50_status` string, or a nominal panel that does not render / throws.
