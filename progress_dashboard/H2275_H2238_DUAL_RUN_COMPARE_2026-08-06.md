## Goal restated (both lanes)

1. Progress shows **nominal burn-down** (promoted / scope / remaining / pct) with a
   kitchen ETA-like strip, not only raw promoted/candidates counts.
2. **medium-50** fields are **live-measured** where the H317 worklist + store exist
   (not a forever-hardcoded `2/50` without a measured flag).
3. **pause_reason** is structured (`code` + label + docs links), not prose-only
   `medium50_status`.

**Fail =:** still only a free-text `medium50_status`, or a nominal panel that does
not render / throws; or rubber-stamp of #1119 with no independent read / no written
adjudication.
