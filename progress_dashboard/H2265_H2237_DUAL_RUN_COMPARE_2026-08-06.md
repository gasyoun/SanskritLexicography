## Goal restated (both lanes)

1. Kitchen distinguishes **generation volume** (store cards written) from
   **clean/promoted outcomes** (ledger `state==clean`, plus promote events if any).
2. Split is **this week + lifetime**, not a bare lifetime `clean_windows/473`.
3. UI surfaces the contrast on the public progress page.

**Fail =:** only `clean_windows/473` without store-growth contrast; or rubber-stamp of
#1107 with no independent read / no written adjudication.
