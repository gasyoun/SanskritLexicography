## 2. Браузерный проход (агент, не MG)

На v6, карточка `gā` (первая в ORDER):

1. Две колонки заполняют ширину окна (>980px).
2. Клик по «привязано к смыслу PWG 2» справа подсвечивает тот же смысл слева.
3. Hover (десктоп) на чип показывает полный немецкий текст, не обрезку в одну строку.
4. Ссылка store раскрывает цветную разметку; до клика стены текста нет.
5. Кнопки approve/reject/1–5 видны внизу, пока колонки скроллятся; после скролла
   ко второй карточке полоса принадлежит уже ей.
6. Вьюпорт 360px: колонки стеком, DE сверху, голос снизу липнет.

На G5: одна карточка — слева немецкий смысл, справа печать, store в details,
`sheet_id` в шапке не изменился.

FAIL браузера = стоп публикации хаба, чинить, не «записать и ехать», если сломаны
п.1, 4 или 5. П.3 в одном браузере с обрезкой — записать (не стоп 20).

## 3. Риски и спайки до коммита архитектуры

| Риск | Почему | Спайка | Если провал |
|---|---|---|---|
| Клон кнопок в `#voteBar` двоит localStorage | Два `textarea` с одним listener | Писать только в скрытый оригинал; клон — `input`/`click` forward | Не публиковать, пока экспорт не совпадает с кликом в полосе |
| `print_panel` на `pwg_de` протаскивает RU через mark_cyrillic | Функция ждала русский | Селфтест «нет кириллицы в .col-de телах» | Рендерить DE без `mark_cyrillic` |
| `max-height: 100vh` режет карточку под sticky header+bar | 220px угаданы | Браузер п.5 | Поднять константу, записать в отчёт |
| G5 pin-ids красный из-за переноса панелей в left/right | Дайджест считал HTML панелей | Дайджест должен покрывать **текст смысла**, не обёртку; если сегодня считает HTML — это стоп 2, не «починить дайджест чтобы прошёл» | Доложить: recut меняет байты презентации, нужен новый lock **только если** нынешний дайджест — HTML. Если дайджест — тела store, обёртка не должна двигать его. Проверить **до** массовой пересборки, на одной карточке |
| Cologne не мержит 0.22.0 | Нет прав | git URL ветки (решение 18) | Не стоп |

Первая спайка по G5 digests — **до** шага 5 целиком: прогнать функцию дайджеста на
старом HTML vs том же тексте в `left`/`right`. Результат выбрать маршрут, не
менять lock вслепую.
