## Критерии приёмки

| # | Критерий | Чем доказывается |
|---|---|---|
| A1 | Ни одна строка с `placement=false` не подаётся как утверждение об отношении к смыслу | Скрипт-проверка по сайдкару: для каждой строки `placement=false` карточка не показывает «пересказывает смысл N» |
| A2 | `placement=true` **только** при реально найденном смысле | Проверка: для каждой `placement=true` ключ `(key1, homonym, norm(target))` есть в индексе PWG. Нарушений 0 |
| A3 | Нормализация не привязала лишнего | Ни одна строка, бывшая `target_sense='*new'`, не стала `placement=true`. **Стоп-условие**, не просто проверка |
| A4 | `out_of_range` не изменился | ≈381 до и после: нормализация на него не влияет по построению; изменение = ошибка в S3 |
| A5 | Канонический store не тронут | `rows=11715` и sha256 `pwg_ru_translated.jsonl` совпадают с исходными |
| A6 | Регрессий нет | `python src/pilot/window_selftest.py` → 211/211 |
| A7 | Селфтесты новых функций | `edition_rel.py` selftest включает позитивы и **негативы** нормализации (S1) |
| A8 | Дельта измерена и записана | `checkable` до/после + распределение `placement_reason` в отчёте прогона и в `REGLUE_SPEC` |
| A9 | Потребители согласованы | Все четыре читают `placement`, ни один не вычисляет «нашлась ли цель» заново |

Команды, доказывающие A5–A7:

```
python src/pilot/window_selftest.py
python src/edition_rel.py --selftest
python src/build_reglue_evidence_sheet.py 2>&1 | grep "cards drawn"
```

## Риски

| Риск | Почему опасен | Смягчение |
|---|---|---|
| **Нормализация слишком агрессивна** | Даст `placement=true` на чужом смысле — тихая ложь, хуже исходного дефекта | Решение 6 (только пунктуация); A3 как стоп-условие; обязательные негативные селфтесты |
| **Асимметричная нормализация** | Нормализовали цель, но не скелет (или наоборот) → новый класс промахов | S2 требует одной функции на обеих сторонах; A2 поймает |
| **`out_of_range` спутан с `not_found`** | Потеряется единственное содержательное различение | A4: число не должно измениться |
| **Гипотеза протекает в факт** | `placement_hypothesis` попадает в `insertion_point` или влияет на `placement` | Архитектурный запрет; проверка: при `placement=false` `insertion_point.target_sense` не изменился относительно исходного сайдкара |
| **Регенерация листов ломает поданные голоса** | Меняется `content_hash` | S7 — проверка перед регенерацией, **остановка** при наличии голосов |
| **Расхождение потребителей** | Часть читает `placement`, часть считает сама | S6 обновляет все четыре в одной волне; A9 |
