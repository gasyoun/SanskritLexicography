# VERIFICATION — reglue2: чем доказывается каждая поставка

[PLAN_RussianTranslation_REGLUE2_CITATIONS_TYPOLOGY_2026-08](https://github.com/gasyoun/SanskritLexicography/blob/master/docs/PLAN_RussianTranslation_REGLUE2_CITATIONS_TYPOLOGY_2026-08.md).
Планка приёмки (решение 16): селфтесты каждого тронутого модуля, пересобранная статья
`gā` целиком, выборочная сверка 50 цитат. Исполнитель работает без человека, поэтому
каждый критерий сформулирован как команда с наблюдаемым исходом, а не как «выглядит
правильно».

## 1. Критерии по поставкам

| Поставка | Чем доказывается | Проходит, когда |
|---|---|---|
| A1 `mbh_locus` | `python src/mbh_locus.py --selftest` | `MBH. 12,8081` → вульгата `12.226.6` и непустой `bori_locus`; запись «только в вульгате» → `bori is None`; при отсутствующем csl-atlas → `unchecked`, **не** `absent` |
| A2 страницы стихов | открыть построенную страницу `12.226.6` | содержит `yadā ca pṛthivīṃ sarvāṃ yajamāno 'nuparyagāḥ` в IAST и чтение BORI рядом |
| A3 тройка координат | `python src/pilot/build_article_site.py --selftest` + глазами карточка `gā` | видно `MBH. 12,8081. = Вульг. 12.226.6 = крит. …`; все три части — ссылки; значка `E` не осталось |
| A4 разбиение `<ls>` | селфтест на строке из замечания | `<ls>ṚV. 4,3,13. 10,18,4</ls>` даёт **две** ссылки; вторая ведёт на `ṚV. 10,18,4` |
| A5 обёртка NWS | замер охвата до и после | охват `ṚV`/`AV` вырос; `AV(P) 9.10,10` и `ṚV 10,108,9` в теле NWS кликабельны; change-файлы в очереди, коммитов в `csl-orig` ноль |
| A6 указатель изданий | пересчитать строки | 18 строк, ни одной пустой ячейки; отсутствие перевода записано словами |
| B1 падежи | `python src/scan_sheet_latin_chrome.py` | ни одного свободно стоящего `Akk`/`Instr`/`Lok` в русских телах; доменная помета `[Gen, unsp]` **не** считается нарушением |
| B2 дифф-классификатор | распределение по знакам на пилоте | ни один знак не берёт больше 70 %; иначе — условие стопа 4 |
| B3 знаки и легенда | глазами карточка `gā` | строка читается как `— §ʰ PW  1〉 приходить.`; легенда один раз вверху; четырёхкратного чипа нет |
| B4 ярлык привязки | поиск по выходу | строки `значение PWG` не осталось; без привязки печатается `новый смысл, в PWG соответствия нет` |
| B5 немецкая склейка | гейт паритета | `gA.de.md` существует; множества точек вставки русской и немецкой склеек совпадают |
| B6 флаг глоссы | отчёт | «следовать за» при `ṚV. 4,3,13` есть в списке флагов; тело текста не изменено |
| C1–C3 публикация | открыть опубликованные адреса | лист и сайт статей показывают новое; issue открыты с типом, степенью и вехой |

## 2. Контрольная таблица «шесть замечаний → где именно видно»

Обязательная часть отчёта. Пересобранная `gā` предъявляется по этой таблице, строка за
строкой.

| Пункт reglue2 | Что требовалось | Где смотреть в пересобранной `gā` |
|---|---|---|
| 1 | Показывать `12.226.6`, а не немой `E`; вести на свой IAST; дать критический адрес и путь к русскому переводу | смысл h0, цитата `MBH. 12,8081.` |
| 2 | Никаких немецких `Akk`, `Instr` в русском тексте | строка NWS в h0: `идти дорогой (Acc., Ins.)` |
| 3 | Немецкая склейка существует и читается | файл `gA.de.md` |
| 4 | Один знак вместо четырёх ярлыков; знак отвечает «в чём именно» | все строки `PW` в смыслах 1–6 |
| 5a | Понятный ярлык привязки | смысл 2, строка NWS |
| 5b | Ригведа и Атхарваведа железно пролинкованы | `ṚV 10,108,9` в смыслах 2 и 3, `AV(P) 9.10,10` в смысле 4 |

## 3. Выборочная сверка 50 цитат

Стратифицированная выборка: 20 `MBH.`, 20 `ṚV.`, 10 `AV.`, из разных парв и мандал, с
фиксированным зерном ради воспроизводимости. По каждой цитате проверяется, что стих, на
который ведёт координата, **содержит заглавную лемму** карточки (свёрнутое сравнение
через `sanskrit_util.nfold`).

Отчёт даёт долю попаданий и — обязательно — **фон**: та же проверка на случайном стихе
той же парвы. Доля без фона ничего не значит; именно так измерялся подогнанный индекс f8
(55.2 % против 1.4 % нуля). Ожидание: попадание существенно выше фона. Результат ниже
фона — регрессия, условие стопа 2.

Промахи не прячутся: список расхождений идёт в отчёт целиком, с указанием, отнесён ли
каждый к точности индекса или к ошибке рендера.

## 4. Замер охвата до и после

Одно число, снятое дважды — до первой правки (шаг 0 реализации) и после. Разбивка по
`MBH.` / `ṚV.` / `AV.` и по слоям PWG / NWS, по **всему** хранилищу, а не по пилоту
(решение 3). Падение любой строки — стоп.

## 5. Риски и разведка

| Риск | Что может пойти не так | Как узнаем заранее | Что делать |
|---|---|---|---|
| Точность подогнанного индекса | вульгатная координата попадает не в тот стих | сверка 50 цитат против фона | если попадание не выше фона — координату не показывать, доложить |
| csl-atlas отсутствует в клоне | критический адрес недоступен | ветка `unchecked` в селфтесте A1 | ничего не печатать о критическом издании; никогда не рисовать «отсутствует» |
| Дифф-классификатор вырождается | почти всё в один знак, как сейчас `restate` | гейт 70 % на пилоте | стоп 4, доложить отрицательный результат, порогов не крутить |
| Пустое тело смысла PWG | дельта неотличима от «всё новое»; медиана три содержательных слова, у 16 % ноль | считается на пилоте до внедрения | такие случаи → `≈` и в список неразрешимых |
| Ложная обёртка цитаты в NWS | испорчен текст статьи | узкий белый список форм | при сомнении не оборачивать: пропуск дешевле порчи |
| Частичное разбиение `<ls>` | выглядит как «второго места нет» | правило «всё или ничего» в селфтесте A4 | не резолвится хоть один локус — тег остаётся как был |
| Пробел в русских изданиях | часть парв не переведена или спорна | заполнение всех 18 строк | писать «нет издания» словами, брать умолчание, отметить в журнале |
| Разъезд поверхностей | лист и сайт статей показывают разное | правка идёт в `_ls_html`, а не в генератор листа | пересобрать обе поверхности одним проходом |

**Разведка до внедрения — одна.** Прогнать дифф-классификатор на пилоте и посмотреть
распределение по пяти знакам **прежде** чем менять вид карточки (шаг 7b перед 7c). Если
классификатор не различает, знаки менять незачем: это будет тот же `restate` под новым
именем.
