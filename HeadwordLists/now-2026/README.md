# now-2026/ — current-csl-orig regeneration of the headword snapshots

The **NOW (2026)** counterpart to the frozen **THEN (2014)** snapshots in
[`../then-2014/`](../then-2014/). Each file is the sorted-unique headword set of the
dictionary as it stands in the **current**
[`csl-orig/v02`](https://github.com/sanskrit-lexicon/csl-orig/tree/main/v02); the
filename count is the count **at the file's first generation** (see the write
contract below). Regenerated by
[`../headword_diff.py now`](https://github.com/gasyoun/SanskritLexicography/blob/master/HeadwordLists/headword_diff.py); then→now deltas are in
[`../NOW_VS_THEN.md`](https://github.com/gasyoun/SanskritLexicography/blob/master/HeadwordLists/NOW_VS_THEN.md).

## Write contract (H6518, 13-10-2026)

`headword_diff.py now` is a **fail-closed, pin-stable, BOM-preserving** exporter:

- **Pinned names** — a regen **overwrites the existing file in place** and never
  renames it, so consecutive regens diff in place instead of churning
  add/delete pairs. A count-bearing name `N` is the count at first generation;
  when the live count drifts off the pin, the name is kept and the drift lands
  in [`NOW_COUNT_DELTA.md`](NOW_COUNT_DELTA.md) (regenerated every run, and
  printed loudly). Re-pinning a name is a deliberate data-refresh PR (it must
  bump the [`../../tests/test_headword_snapshots.py`](https://github.com/gasyoun/SanskritLexicography/blob/master/tests/test_headword_snapshots.py)
  floors, the prose numbers, and check downstream consumers).
- **BOM preservation** — the output byte-begins with the then-2014 sibling's
  BOM where that sibling has one (`MW-unique-key1` does; its key2 sibling does
  not) and never gains one where the sibling has none.
- **Fail-closed** — with no csl-orig sources found, `now` writes nothing and
  **exits non-zero** with a loud stderr message naming the `CSL_ORIG_V02`
  override; it can no longer exit 0 after writing zero snapshots.

Selftest: [`../headword_diff_selftest.py`](https://github.com/gasyoun/SanskritLexicography/blob/master/HeadwordLists/headword_diff_selftest.py)
(offline, fixture-based — `python3 HeadwordLists/headword_diff_selftest.py`).

## Both keys

- **key1** — the normalised machine key (raw `<k1>`, accent-stripped); use for
  matching / dedup / joins.
- **key2** — the **print / citation form**, re-extracted as clean **SLP1** (keeps the
  `/` udātta accent, `-`/`—` compound markers, `(...)`, `*`, `˚`). The 2014 key2 files
  were in the legacy Cologne numeric transliteration (`am2s4a` = aṃśa); these are the
  modern SLP1 form, so key2 here is the print-ready headword shape (it cannot be
  line-diffed against the numeric 2014 file — that delta is a format migration).

key2 is extracted by stopping the capture at the `¦` headword separator, stripping
`{#..#}` markup, and splitting comma-lists into individual forms (a naïve
`<k2>([^<]*)` over-captures entry body text / compound blobs).

## Caveats

- **Order is normalised Sanskrit collation** (varṇa-krama over SLP1), *not* the
  inconsistent legacy order of the THEN files — compare by **set**
  (`comm`/`sort -u`/the script's set-diff), not a raw line `diff`.
- **PD** is not in csl-orig (`CODE2DIR['PD']=None`); NOW files are written from
  `PD_SRC` when that path exists
  (`PD-unique-key1-104959.txt`, `PD-unique-key2-104968.txt`, H1365). **PWK** is
  from csl-orig `pw` (Böhtlingk's *kürzere Fassung*).
- Counts drift as csl-orig is corrected; re-run the script to refresh — the
  pinned filename is kept and the live count is recorded in
  [`NOW_COUNT_DELTA.md`](NOW_COUNT_DELTA.md) (write contract H6518).
