## What this is

AK is **not in CDSL** ([H3862 trap](https://github.com/gasyoun/Uprava/blob/main/CHANGELOG.md):
"Medini and Amara recorded as ABSENT - not in CDSL") — `union_headwords.tsv`
carries zero AMAR rows, so no dictionary-overlap surface ever connected AK to
the CDSL estate. Until now only the DOMAIN level existed (semdom ↔ AK vargas,
A58). This dataset adds the **lemma level**: every AK lemma (per varga/synset)
joined against the 15-dict CDSL union key.

## Headline numbers (14-09-2026 build)

- AK side: 24 vargas, **5,590 synsets**, **14,036 lemma instances**, **9,759 distinct** lemmas (Cologne `AMAR/amar.txt`).
- Exact SLP1 equality vs the union key: **13,559/14,036 instances (96.60%)**, **9,310/9,759 distinct (95.40%)**.
- Misses: **449 distinct** AK-only forms — mostly compounds (`kzIrasAgarakanyakA`), inflected forms (`mAtaraH`), and accent-bearing/Vedic shapes (`fBava`); 64 of the 449 are accent/case-fold near-misses, **counted as a diagnostic only, never promoted to matches**.
- Matched instances attest in up to 15 CDSL dicts; modal depth 8–10 dicts. Weakest varga coverage AK-3.4 (90.85%), largest varga AK-3.3 (3,990 instances, 93.83%). Full spread in the stats JSON.
- The census's 8,353 (varga,lemma) figure (A58 thematic axis, curriculum-cut) counts a different slice; this build's universe is ALL lemmas of amar.txt — 14,036 instances / 9,759 distinct.

## Method

`parse_amar` is **vendored verbatim** from `data/semdom_ak_bridge.py` (H742)
so both AK lanes read the source through the same normalization (strip
trailing gender code after last `-`). The join is exact SLP1 string equality
on the union key — the same standard as `data/headword_overlap_matrix.py`
(H684); the union's own `UNION.md` normalization (homograph collapse, feminine
folding) is already baked into the key, so no extra normalization is applied.

Run:

```
python data/ak_lemma_cdsl_crosswalk.py            # rebuild TSV + stats
python data/ak_lemma_cdsl_crosswalk.py --selftest # 30-lemma sample verify, exit 1 on any drift
```

**Verify (14-09-2026, OxAlpha (opencode/z-ai/glm-5.3-flash)):** `--selftest`
PASS — 30/30 seeded rows re-verified through an independent linear re-scan of
`union_headwords.tsv` + independent amar.txt re-parse; canaries `deva` (14
dicts), `svarga`, `nara` (12 dicts) eyeballed exact.
