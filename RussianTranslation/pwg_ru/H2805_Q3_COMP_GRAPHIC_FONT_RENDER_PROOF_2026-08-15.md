# H2805 — проба шрифтов и рендера для графической пометы позиции в сложном слове (॰- / -॰)

_Created: 15-08-2026 · Last updated: 15-08-2026_

Доказательная база для листа развёртки §6.3 стилевого свода
([PWG_RU_STYLE_GUIDE_OF_RECORD_2026-07.md](https://github.com/gasyoun/SanskritLexicography/blob/master/RussianTranslation/pwg_ru/PWG_RU_STYLE_GUIDE_OF_RECORD_2026-07.md)):
голос MG 15-08-2026 постановил передавать позицию слова в сложном слове **графически**
(по Кочергиной, «кружок» с дефисом), а не словами; открытыми остались слой применения,
тултип и **доступность знака в шрифтах** потребителей. Замеры выполнены Fable 5
(`claude-fable-5`) 15-08-2026 на реальных установленных шрифтах этой машины (324
семейства, fontTools cmap) и растровой пробой реальных файлов шрифтов (Pillow) —
не в терминале. Хендофф:
[H2805](https://github.com/gasyoun/Uprava/blob/main/handoffs/H2805-Fable_SanskritLexicography_h1306-q3-comp-graphic-revote_15.08.26.md).

## 1. Кандидатные кодовые точки «кружка»

| Знак | Кодовая точка | Природа | Прецедент |
|---|---|---|---|
| ॰ | U+0970 DEVANAGARI ABBREVIATION SIGN | родной деванагарский знак сокращения, сидит у базовой линии | индийская типографика деванагари |
| ˚ | U+02DA RING ABOVE | спейсинг-модификатор, сидит вверху | **уже в базе карточек**: PWG-оцифровка помечает усечённый член `{#˚hita#}`, `{#˚DIyatAm#} `— тот же кружок, которым набраны санскритские сегменты стора |
| ° | U+00B0 DEGREE SIGN | знак градуса, сидит вверху | печатная традиция словарей (кружок MW-типа; визуально = «кружок» Кочергиной) |

Оцифровка Кочергиной (SamudraManthanam `corpus.db`, источник 749) в эту сессию
непроверяема — локальная копия базы пустая (0 байт, артефакт не подтянут); утверждение о
её знаке в таблицу не внесено.

## 2. Покрытие установленными шрифтами (fontTools, 324 семейства, 15-08-2026)

| Знак | Шрифтов с глифом | Из стека веб-карточки (`Segoe UI, Roboto, sans-serif`) |
|---|--:|---|
| ॰ U+0970 | 21 | **Segoe UI — НЕТ**; есть только в Nirmala UI (системный fallback деванагари), Arial Unicode MS, Noto Sans, Sanskrit 2003, Siddhanta и др. специализированных |
| ˚ U+02DA | 271 | Segoe UI ДА, Arial ДА, Times New Roman ДА, Consolas ДА, Calibri ДА |
| ° U+00B0 | 315 | все перечисленные ДА |

## 4. Следствия по потребителям

| Потребитель | Что происходит с ॰ U+0970 | С ˚ / ° |
|---|---|---|
| **Веб-карточка** ([build_article_site.py](https://github.com/gasyoun/SanskritLexicography/blob/master/RussianTranslation/src/pilot/build_article_site.py), стек `-apple-system, Segoe UI, Roboto, sans-serif`) | браузер спасает per-glyph fallback'ом (Windows → Nirmala UI; macOS → Devanagari MT; Android → Noto Sans Devanagari); строка становится двухшрифтовой — кружок чуть иного веса и посадки, у базовой линии, не вверху; на минималистских Linux-сборках без шрифтов деванагари — тофу | рендерится самим Segoe UI/Roboto, строка однородна |
| **Экспорт MDF** ([export_mdf_pwg_ru.py](https://github.com/gasyoun/SanskritLexicography/blob/master/RussianTranslation/src/pilot/export_mdf_pwg_ru.py) → SIL Toolbox/FLEx/Lexique Pro) | типовые SIL-шрифты (Charis SIL, Doulos SIL) деванагари **не покрывают** → реальный риск тофу у стороннего потребителя | ˚/° в SIL-шрифтах есть |
| **PDF** | собственного PDF-конвейера в репо нет (единственные `pdf`-ссылки — `servepdf.php` на кёльнские сканы); печать веб-карточки в PDF наследует браузерный fallback и **вшивает второй шрифт**; любой будущий одношрифтовый PDF-генератор (Times New Roman и т. п.) даёт тофу — растровая строка TNR выше | однородно в любом сценарии |

## 5. Итог для листа

1. **Форма «кружок» реализуема без шрифтового риска**: ˚ (U+02DA — знак, которым уже
   набраны усечённые члены в санскритских сегментах базы карточек: `{#˚hita#}`) и °
   (U+00B0) покрыты 271/315 шрифтами из 324, включая весь стек веб-карточки и печатные.
2. **॰ (U+0970) в русском тексте — двухшрифтовая строка всегда**: ни один шрифт стека,
   кроме fallback'а, его не несёт; кириллицу и ॰ вместе на этой машине несёт только
   Arial Unicode MS (легаси-шрифт, из поставки Windows давно исключён).
3. Визуально ॰ в Nirmala UI ≈ ° — то есть желаемый «кружок Кочергиной» читатель получает
   в обоих случаях; выбор кодовой точки — вопрос надёжности, не формы.
4. Слой применения независим от глифа: замена видимого текста формулы на кружок с
   тултипом на **рендере** (§3.1 свода) покрывает 102 карточки базы и ~2,1 тыс. будущих
   корпусных вхождений без репроцессинга; правка **в базе карточек** требует реочереди и
   несёт риск для `{%…%}`-якорей (сам глиф в якорный набор §7.3 не входит — якоря
   `{#…#}`/`ls`/`ab` байт-в-байт не меняются, риск только при правке текста вокруг них).
