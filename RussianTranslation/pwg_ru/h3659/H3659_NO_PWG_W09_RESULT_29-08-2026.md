| field | value |

| `budget_stops` | 16 · `conn_errors` 0 · `kill_timeouts` 0 |

Recorded separately per the `/pwg-bounded-run` rule: creation bills ~20× read and a combined
total hides it. `subagent_tokens` (1 587 259) is the legacy misnomer for the sum.

**The correction.** [FINDINGS §602](https://github.com/gasyoun/SanskritLexicography/blob/master/FINDINGS.md),
written earlier today, says the cost guard fires because "Max-route calls return no usage
telemetry". **That cause attribution is too strong and this window disproves it.** The raw
envelope of the `gl_ana` refusal — captured by `write_failed_envelope` — carries
`"total_cost_usd": 0.30507280000000003` alongside a full `cache_creation.ephemeral_1h_input_tokens`
breakdown. The CLI *does* report per-call cost.

[`gateway_route.py`](https://github.com/gasyoun/SanskritLexicography/blob/master/RussianTranslation/src/pilot/gateway_route.py)
sets `cost_evaluable = True` whenever `total_cost_usd` is a number, and then **rule 3 deliberately
demotes the telemetry to `cost_evaluable = False` on a content failure**, "so the ledger never
reports a failed call as priced". This window has content failures, so its `false` is that
demotion working as designed — **not** absent telemetry.

What stands from §602 is the *mechanism*: `budget_cap` + `not _durable_cost_evaluable` stops the
run at the top of the drain loop, before any work is pulled, and no human authorization clears it.
What does **not** stand is the claim that the lane has no cost telemetry at all. Why the
probe-only first attempt was unevaluable — the probe path never populating a priced reservation —
is now a separate, answerable question, and it is not the same thing as dormant billing.

## `--max-calls 8` was too small for a 5-card window

`translate_agents_spent: 5` + `heal_agents_spent: 3` = 8, so the ceiling was consumed before
`jaw_ayus` and `kast_ur_i` were ever attempted. A no_pwg window budget must leave headroom for
per-card retries and heal groups: **≥ ~2.5 × card count**, not 1.6 ×. The two unrun keys cost
nothing and remain queued.
